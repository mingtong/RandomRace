# 随机竞速：试玩原型

在 Unity 中打开 `RandomRace.unity` 并按 Play。若场景尚未创建，可选择菜单 **Random Race → Create Prototype Scene**。

- 鼠标悬停道路可预览路线与体力消耗，点击可到达的道路格移动；每走一格消耗 1 点体力，可以分多次移动。
- 初始体力 3 点，每次自己的回合开始时恢复 2 点，上限 8 点。点击「结束回合」让 3 个机器人依次行动。
- 青色代表可到达，橙色是预览路线，红色表示体力不足；金色棋盘格是终点，水域与岩石不可通行。棋子可以处于同一格。
- 每人每局可使用一次恢复 2 点体力的技能。每人开始有一张卡，之后每个自己的回合抽一张，手牌上限 3 张。能量卡恢复最多 2 点体力，减速卡令距离终点最近的对手减少最多 2 点体力（同距离按玩家顺序选择）。这些是暂定规则。
- 任何人到达终点立即获胜；胜利后可再来一局。对局中重新开始需要再次确认。
- 界面会根据窗口大小缩放，使用系统中文字体。支持的字体因系统安装情况而异。

在 Unity 中运行 **Random Race → Run Rule Checks**，查看 Console 中的规则检查结果。核心规则位于 `RaceRules.cs`，画面、输入和动画位于 `RaceView.cs`。
